# DNHDD Policy Review Beamer

This directory contains the monochrome academic Beamer conversion of the supplied policy-review PDF.

Build with:

```sh
pdflatex -interaction=nonstopmode DNHDD_Policy_Review_Beamer.tex
pdflatex -interaction=nonstopmode DNHDD_Policy_Review_Beamer.tex
```

The source uses standard Beamer defaults, black/white typography, split frames for dense tables, and preserves the original sections, observations, caveats, sources, evidence gaps, and reform proposals.
